## 正文

今天把一个网页游戏完整走了一遍：

代码评审 → V2.0 PRD → 改代码 → 软件测试 → GitHub Release。

最戳我的不是“又写了多少功能”，而是发现：

1️⃣ 能运行，不等于能发版  
2️⃣ 没有明确终局，游戏会无限拖  
3️⃣ 没有随机种子，倍速同果只是口号  
4️⃣ 调试接口不隔离，玩家能改数据  
5️⃣ 没测试，修一个坑可能埋三个坑  

最后 V2.0 做完了：

固定 1/60 秒步长  
双水晶平局  
第 15 回合终局  
每方最多 12 个单位  
三档 AI  
13 项自动化测试全过  
GitHub Release 已发布  

今日结论：  
真正的 V2.0，不是功能更多，而是终于能被验证、复现和发布。
